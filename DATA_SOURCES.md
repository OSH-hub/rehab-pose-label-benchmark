# Data sources

This repository contains no dataset files, reference annotations, video frames, participant-level tables or model weights. Each dataset must be obtained from its provider and used under the provider's terms. The software license of this repository does not apply to any dataset.

| Dataset | Use in the manuscript | Source | Access terms stated by the provider |
|---|---|---|---|
| REHAB24-6 | Training and internal evaluation (Camera17, Camera18) | https://doi.org/10.5281/zenodo.13305826 | CC BY-NC 4.0; academic or nonprofit research use; cite the provider paper |
| UCO Physical Rehabilitation (RGB and 2D annotations) | External evaluation | Provided by the UCO investigators on request | Research use only; redistribution not permitted; citation required |
| UCOPhyRehab++ | Derived-modality release of the UCO data | https://doi.org/10.5281/zenodo.17935737 | See the Zenodo record |
| Penn Action | External evaluation | https://dreamdragon.github.io/PennAction/ | See the project page |
| KERAAL | Agreement with a reference estimator | Original project provider | See the provider's terms |
| REHAB26-ViewAngles | Agreement with a reference estimator | https://doi.org/10.5281/zenodo.23018128 | CC BY-NC 4.0 |

The REHAB24-6 skeleton and marker names that appear in the parser and in the synthetic test fixture generator follow the dataset documentation.
